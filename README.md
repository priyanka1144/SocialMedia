# SocialMedia

**Task 2: Social Media Platform ("adda")**

## Features
- User registration and login (bcrypt + JWT)
- User profiles with bio, followers, following and post counts
- Create and delete posts (280 characters)
- Comments on posts (add and delete your own)
- Like / unlike posts
- Follow / unfollow users, "Following" feed, user search and suggestions

## Tech stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: SQLite (built-in node:sqlite, Node.js 22.13+ required) - tables: users, posts, comments, likes, follows

## Run locally
```bash
npm install
npm start
```
Open http://localhost:3000
